# Exemplar AI Chatbot

hiii

This is a chatbot i made for fun in IDLE Python so cool right??
Basically it's a synonym replacer and it does cool stuff with words it learns. check newest branches for newest updates and more things.
It has NO FILTER meaning you can technically teach it to curse. you probably shouldn't do that though. oh and if you want to make it quote stuff you need to put your quotes like " this " so it has seperate tokens for them.
btw it can now delete its own memory, so if it forgets stuff, just teach it again and use the word more often.
